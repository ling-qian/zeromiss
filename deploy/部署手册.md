# BizBot 部署手册（微信客服合规版 v2）

目标：第一家试点店，**签约当天上规则版（企微后台配FAQ），2-4周后升 AI 版（本文档）**。
两个版本共用同一知识库（tools/kb_import.py 生成），升级无感。

---

## 一、前置清单（装机前 2-4 周启动，按周推进）

| 事项 | 谁 | 周期 | 说明 |
|---|---|---|---|
| 1. 备案域名 | 老板（公司/个体户主体） | **2-4周硬周期** | 服务器在国内就必须备案；本周就启动 |
| 2. 云服务器 | 老板 | 当天 | 2核4G 轻量云即可（腾讯云轻量 ¥50-80/月），装 Docker |
| 3. SSL 证书 | 老板 | 当天 | 云厂商免费签 nginx 格式，放 deploy/certs/ |
| 4. 店家注册企微 | 店主（电话指导40分钟） | 当天 | 个体户营业执照可注册，免费；客人不动，只做新客入口 |

## 二、企微侧配置（电话陪店家操作，拿 5 个值）

1. **企业ID**：work.weixin.qq.com → 我的企业 → 企业信息 → 复制（`WECOM_CORP_ID`）
2. **开通微信客服**：管理后台 → 应用管理 → 微信客服 → 创建客服账号 → 复制账号ID（`WECOM_KF_OPEN_KFID`，wk开头）
3. **开启 API**：微信客服 → API → 开启 → 随便填一个 URL（如 `https://你的域名/wecom/kf/callback`）→ 自己生成 Token 和 EncodingAESKey（**43位**）→ 此时验证会失败，**先跳过**，值先记下（`WECOM_KF_TOKEN` / `WECOM_KF_AES_KEY`）
4. **拿 Secret**：微信客服 → 查看Secret → 发到企业微信（`WECOM_KF_SECRET`）
5. **客服码**：客服账号详情 → 客服码 → 打印/挂美团店铺页/小红书私信自动回复

## 三、服务器部署（我做，或照抄四步）

```bash
# 1. 上传项目到服务器（git clone 或 scp）
# 2. 配置
cd bizbot/deploy && cp .env.example .env && vi .env   # 填二节的5个值+密码+LLM key
# 3. 起服务
bash deploy.sh
# 4. 回企微后台完成 API 回调验证（第二节的URL此时已可用）
```

## 四、上线验收三测（缺一不交付）

1. **回调验证**：企微后台 API 配置保存 → 显示"验证成功"
2. **欢迎语**：手机微信扫客服码 → 3秒内收到欢迎语
3. **语义回复**：发"洗头多少米/剪个头发贵不贵" → AI 回价格（换了说法也能接住=大模型版上线）
4. **转人工**：说"我要退卡" → 企微群收到店主提醒 + AI 静默30分钟

## 五、常见故障速查

| 症状 | errcode | 处理 |
|---|---|---|
| 发消息失败 | 40014/42001 | token 过期，通道自动刷新；持续出现查系统时间 |
| 验证不过 | 签名错误 | AES_KEY 必须43位原样复制，别多空格 |
| 收不到消息 | — | `docker compose logs bizbot | grep 微信客服`；回调丢了有20s轮询兜底，查轮询日志 |
| AI 和店主同时回客人 | — | 转人工后默认静默30分钟（WECOM_KF_HOLD_MINUTES 可调） |

## 六、数据与回滚

- 数据库/知识库/游标在 docker volume `bizbot_data`，每天自动备份（app内置，backup模块）
- 回滚：`docker compose down && git checkout 上一版本tag && bash deploy.sh`
- 数据库手动恢复：data/ 下最近备份包解压覆盖 bizbot.db
