# 本地安装双形态说明（Mac 开发机 / Windows 店主机）

## 形态一：MacBook 直接跑源码（老板自用/演示，零打包）

技术栈纯 Python 跨平台（已验证无 Windows 专属依赖），Mac 上三条命令：

```bash
cd bizbot
pip3 install -r requirements.txt
python3 app.py --port 8080 --username boss --password 你的密码
```

浏览器打开 `http://localhost:8080` 即管理台。
微信客服接待：`.env` 填好 WECOM_* 五项后启动即可（轮询模式，无需公网域名）。

> 注意：给**店主**装不需要 Mac 版——店主群体全是 Windows/手机。
> Mac .app 打包还要 $99/年开发者签名，自用不划算，直接跑源码。

## 形态二：Windows exe（店主装机包）

PyInstaller 不支持跨平台：Mac 上打不出 Windows exe。方案=**GitHub Actions 云端自动打包**：

1. 仓库推到 GitHub（public 仓库免费）
2. Actions 页面 → build-windows-exe → Run workflow
3. 运行完在 Artifacts 下载 `BizBot-windows.zip` → 发给店主/拷 U 盘
4. 店主解压，双击 `启动店长助手.bat`（自动开机自启可后续加）

每次代码更新重新 Run 一次即出新包。workflow 内置冒烟验证（exe 启动后 API 就绪才算打包成功）。

### 已知坑（首版交付教程里必须写）

- **杀毒误报**：PyInstaller exe 常被 Defender/360 标记，教程附"添加信任"一步截图
- **首次启动慢**：单目录版首次解压 SQLite 文件约 10-20 秒，正常
- **微信客服接待前提**：店家企微后台完成 API 开启（部署手册第二节），exe 填 .env 后重启

### 云托管（升级项，非默认）

备案域名下来后可切云端部署（deploy/docker-compose.yml + 部署手册），
解决"店主电脑关机=夜间漏客"。可作为对店主的月费升级点（约¥60/月）。
