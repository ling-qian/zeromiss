# BizBot 门店知识库录入工具

给店主的**填表 → 一键导入**工具：不用手工在系统里一条条编辑，只要填好一张 Excel，
运行一条命令就能变成 BizBot 机器人能直接用的知识库文件。

## 这套工具包含什么

| 文件 | 用途 |
| --- | --- |
| `门店知识库模板.xlsx` | 店主填写的空白模板（含示例行和填写说明） |
| `kb_import.py` | 导入脚本：把填好的 Excel 转成知识库 JSON |
| `README.md` | 本说明 |

## 店主：三步搞定

### 第 1 步：拿模板

拿到《门店知识库模板.xlsx》，里面有 3 张表（Sheet）：

- **FAQ**：客人最常问的问题和标准回答
- **SOP**：门店的流程/场景该怎么应对（如到店接待、预约取消）
- **行业知识**：本行业的常识科普（如"什么是头皮护理"）

每张表的第 2 行是一行**黄色示例**，照着它的样子往下填就行。示例行以「[示例]」开头，
导入时会自动跳过，不用删。

### 第 2 步：填表（每张表 6 列）

| 列 | 要不要填 | 怎么填 |
| --- | --- | --- |
| 问题 / 场景 / 主题 | **必填** | 客人问的原话，或流程/主题名称 |
| 触发关键词 | **必填** | 机器人靠这些词认出客人问的是什么。**多个词用逗号隔开**，如 `染色,染发,染头发`，建议 3~8 个 |
| 标准答案 / 动作 / 内容 | **必填** | 机器人识别后会**原样回复**这段话，请写门店真实口径；**价格要直接写在这里** |
| 排除词 | 选填 | 客人问题里含这些词时**不**套用本条回答，防止答非所问 |
| 推荐追问 | 选填 | 回答完再追问客人的一句话 |
| 参考价格（元） | 选填 | 只是给导入时做检查用（填了必须大于 0）；**机器人不会自动报这个价** |

**三件事最容易踩坑：**

1. 关键词、答案、问题这三列**不能空**，空了导不进去；
2. 关键词请用逗号（中英文都行）、顿号或分号分隔，**不要写在同一个格子里不分隔**；
3. 想让机器人报价格，就把价格**写进答案那句话里**（如"单染 98 起"），价格列只是核对用。

### 第 3 步：交回来

把填好的 Excel 发回给运营/技术即可。自己动手导入的话：

```bash
cd tools
python3 kb_import.py 填好的表.xlsx --out knowledge_base.json
```

- 导入成功会打印各类别导入的条数；
- 有问题（漏填、价格填 0 等）会**一次性列出所有错误，并标明第几行**，改完重新跑一遍就行；
- 加 `--include-example` 可以连示例行一起导入（一般不用）。

导入生成的 `knowledge_base.json` 放到 BizBot 的 `config/knowledge_base_data.json`
（或按部署要求放置）并重启服务后即生效；之后仍可在 BizBot 管理界面里继续增删改。

## 运维：导入命令速查

```bash
python3 kb_import.py 门店表.xlsx                          # 输出到 ./knowledge_base.json
python3 kb_import.py 门店表.xlsx --out /path/to/kb.json   # 指定输出路径
python3 kb_import.py 门店表.xlsx --include-example        # 保留示例行
```

退出码：`0` 成功；`1` 校验失败（错误已列出）；`2` 缺少 openpyxl 依赖。

## 输出格式（技术说明）

输出 JSON 顶层固定为 `{"tuning": [...], "faq": [...], "sop": [...], "industry": [...]}`，
与 `config/knowledge_base.py` 的 `KnowledgeBase._load_from_file` 加载格式完全一致；
条目字段为 `question` / `keywords` / `answer` 及可选 `follow_up` / `exclude_keywords`，
与现有 `config/knowledge_base_data.json` 完全一致，BizBot 加载器无需任何改动。

模板默认没有"调频规则（tuning）"表；如门店需要，可自行在 Excel 中添加名为
`tuning` 或 `调频规则` 的工作表，列结构相同，导入脚本会自动识别。

## 已知限制

- 仅支持 `.xlsx`（新版 Excel 格式），不支持老式 `.xls`；
- 关键词匹配是字面包含匹配，同义说法需要分别列为关键词；
- 参考价格列不写入 JSON，只做校验提醒；
- 导入是全量生成（生成的是这家店自己的知识库文件），不与现有线上数据自动合并。
